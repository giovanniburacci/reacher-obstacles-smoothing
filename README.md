# Hierarchical Reinforcement Learning and Reward Machines for Sparse-Reward Tasks with Policy Output Smoothing

This is a fork of [neverorfrog/reacher-obstacles](https://github.com/neverorfrog/reacher-obstacles), based on the paper extended "Exploiting Robot
Abstractions in Episodic RL via Reward Shaping and Heuristics", extend with the framework for dynamically learning in an abstract environment, reward machines implementation, and a policy output smoothing technique based on reward shaping.
